How to test: Connect your PS5 DualSense controller via USB or Bluetooth to your Mac. Open this page in Chrome or Edge. Press any button on the controller — the browser will detect it automatically via the Gamepad API. Move the sticks and triggers to see live input values.

What this proves: That we can read all PS5 controller inputs (sticks, triggers, buttons) in real-time through a web browser with zero dependencies. The actual project will use a Python backend (FastAPI + pygame/pyserial) to read the controller and send commands to the Arduino — but this confirms the DualSense hardware works and is readable on your Mac.
