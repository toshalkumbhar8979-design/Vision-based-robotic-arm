Digital Twin & Simulation Pipeline

How the Digital Twin Synchronizes:
1. Baby ROS / Three.js URDF Loader: 3D CAD mesh files are parsed using standard URDF joint origins and rotational axes.
2. Bi-Directional Telemetry: Moving sliders or teleoperating with PS5 updates both the physical servos via Arduino and the 3D Digital Twin model simultaneously in 30Hz real-time.
3. Safe Motion Validation: Digital Twin can be used in offline simulation mode to preview trajectory execution before sending power to physical motors.

Cartesian Inverse Kinematics (IK) Teleoperation Architecture

1. Left Stick (X / Y): Moves the end-effector in Cartesian table space (centimeters relative to base).
2. Right Stick (Z): Moves end-effector Z-height up and down towards table.
3. R1 / L1 Bumpers: Rotates Wrist Roll clockwise / anti-clockwise.
4. Cross (×) / Circle (○) Buttons: Changes Wrist Pitch angle.
5. R2 / L2 Triggers: R2 slowly closes gripper claw; L2 locks gripper position.

Safety Rules (Decision #5 & #24)

• The policy is only as good as its perception — if the block or origin tag is not detected the arm HOLDS (frozen), never guesses.
• All model outputs pass through the EMA low-pass filter (alpha=0.25) before reaching the servos — zero jerk guaranteed.
• E-stop (software or physical) immediately halts autonomous mode and returns control to the operator.
• First run: keep a hand near the E-stop, verify the reach direction matches the block before full cycles.
